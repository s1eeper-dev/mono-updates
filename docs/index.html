MONO

MONO는 한 사람이 자기 Windows PC에서 쓰는 개인 일정 관리 프로그램입니다. 할 일·프로젝트·자료·시간 기록을 그 PC 안에 저장합니다.

구글 드라이브 연결

사용자가 직접 연결하면, 할 일·자료에 붙인 그림·파일(첨부)의 사본을 사용자 본인의 구글 드라이브 ‘MONO 첨부’ 폴더에 두고, 사용자의 다른 PC에서 받아 옵니다. 권한은 MONO가 만든 파일만 다루는 drive.file 하나이며, 드라이브의 다른 파일은 보지 않습니다.

개인정보처리방침

MONO is a personal schedule app for Windows, used by one person on their own PCs. If the user connects Google Drive, MONO stores copies of the user's attachments in a “MONO 첨부” folder in the user's own Google Drive so the user's other PCs can download them. MONO uses only the drive.file scope and never reads other Drive files. Privacy Policy
