MONO 개인정보처리방침

시행일 2026-10-29 · MONO

1. MONO가 다루는 정보

MONO에 적은 할 일·프로젝트·자료·시간 기록과 붙인 첨부는 사용자의 PC(MONO 기록 폴더)에 저장됩니다. MONO를 만든 사람은 이 정보를 받거나 보관하는 서버를 두지 않습니다.

2. 구글 사용자 데이터

  • 사용자가 ‘구글 계정 연결’을 하면 MONO는 https://www.googleapis.com/auth/drive.file 권한만 요청합니다. 이 권한으로 MONO가 만든 파일만 만들고·읽고·고치고·휴지통으로 옮깁니다.
  • MONO가 만드는 파일은 첨부의 사본이며, 사용자 본인의 구글 드라이브 ‘MONO 첨부’ 폴더에 둡니다. 사용자의 다른 PC가 같은 계정으로 연결하면 그 사본을 받아 옵니다. MONO에서 지운 첨부는 30일 뒤 드라이브 휴지통으로 옮깁니다.
  • 드라이브의 다른 파일·문서·사진, 메일, 연락처는 보지 않습니다.
  • 연결된 계정을 설정 화면에 보여 주려고 그 계정의 전자 우편 주소를 읽어, 그 PC에만 저장합니다.
  • 구글이 주는 연결 열쇠(토큰)는 그 PC에만 저장하고 다른 곳으로 보내지 않습니다.

3. 정보가 가는 곳

  • 구글 — 사용자 본인의 구글 드라이브(위 2).
  • 사용자가 켠 경우의 동기화 중계소 — 사용자 본인의 Cloudflare 계정에 사용자가 만든 것. 할 일 같은 기록 행이 가며, MONO를 만든 사람은 볼 수 없습니다.
  • 링크 미리보기 — 사용자가 적은 인터넷 주소의 제목·그림을 그 주소에서 가져옵니다(설정에서 끌 수 있음).
  • 업데이트 확인 — 새 버전 안내 파일을 GitHub에서 받습니다. 사용자 정보는 싣지 않습니다.

4. 나누기·쓰임

구글 사용자 데이터를 포함한 사용자 정보는 다른 사람·회사와 나누거나 팔지 않고, 광고·분석에 쓰지 않으며, 인공지능 모델 학습에도 쓰지 않습니다. 구글 API에서 받은 정보의 사용과 다른 앱으로의 전달은 Google API 서비스 사용자 데이터 정책(제한적 사용 요건 포함)을 따릅니다.

5. 끊기·지우기

  • MONO › 설정 › 동기화 › 첨부 파일 › [연결 끊기] — 구글 쪽 허락도 거둡니다. 또는 Google 계정 › 보안 › 타사 앱 및 서비스 연결에서 MONO를 지웁니다.
  • 드라이브의 ‘MONO 첨부’ 폴더는 사용자가 언제든 지울 수 있습니다. PC의 기록은 MONO 기록 폴더를 지우면 없어집니다.

6. 바뀌면

이 방침이 바뀌면 이 페이지에 새 시행일과 함께 올립니다. 문의는 MONO 구글 연결 화면에 보이는 지원 이메일로 해 주세요.

Summary (English). MONO is a personal Windows app used by one person. Its data stays on the user's own PCs. If the user connects Google Drive, MONO requests only the drive.file scope and creates, reads, updates and trashes only files it created: copies of the user's attachments in a “MONO 첨부” folder in the user's own Drive, so the user's other PCs can download them. It reads the account e-mail address only to show which account is connected, and keeps it and the OAuth token on that PC only. MONO does not access other Drive files, mail or contacts. The developer runs no server that receives user data. Google user data is not shared, sold, used for advertising or analytics, or used to train AI models. MONO's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Disconnect any time in MONO (Settings › 동기화 › 첨부 파일 › 연결 끊기) or in your Google Account security settings. Effective 2026-10-29.
